EDR FINAL SECTION A: CODE AND EVIDENCE

This package contains the code and evidence for final Section A. Main experiment
outputs are preserved from 17 October 2026. Figure 7 and the final analytical
extension were completed on 2 November 2026. The original run
time and environment are in evidence/verification.json.

CODE AND SOURCE OWNERSHIP
author_source/author_experiment1.py is the author's original Experiment 1 script,
preserved unchanged. Its original repository filename is 实验一.py.
replication/reproduce.py is the project-added reproduction and validation code.
It runs the author script, suppresses interactive plot windows, exports data,
checks independent solutions and published curves, and performs the alpha sweep.
The root reproduce.py only launches this project implementation.
The author repository is the source of the preserved original simulation.
The project wrapper and saved validation results are supplied in this package.

Author repository: https://github.com/fylimas/EDR
Paper: Fangyuan Li (2026), Equilibrium Drift Restriction: A Control Strategy
for Reducing Steady-State Error Under System Inconsistency, Mathematical and
Computational Applications 31(1), 11.
DOI: https://doi.org/10.3390/mca31010011
The published paper is included as author_source/EDR_published_paper.pdf (CC BY 4.0).
author_source/author_sensitivity.py is the unchanged author Experiment 2.
replication/sensitivity_figure7.py is the project-added Figure 7 reproduction.
replication/design_analysis.py is the project analytical design extension.

RUN WITH PYTHON 3.12
Extract the ZIP, open a terminal in this folder, and run:
    python -m pip install -r requirements.txt
    python reproduce.py
    python replication/sensitivity_figure7.py
    python replication/design_analysis.py

Run in a copy if you want to keep the supplied 17 October outputs: reproduce.py
overwrites generated files under evidence/. It does not modify source files.
The optional --extra-deps PATH argument uses an existing local package folder.
It is unnecessary after installing requirements.txt.

Expected output: six main cases at 1000 output times each, 6000 trajectory rows,
six original author figures, and 12 alpha-sweep cases at 2001 times each.
The sweep covers four alpha values and three frequencies; alpha_sweep.csv has
four summary rows, while alpha_sweep_trajectories.csv has 24012 rows.
The program prints its checks and writes evidence/verification.json. Python
3.12 may emit SyntaxWarning messages for plot-label escapes in the preserved
author script; the original run log records these warnings.

EVIDENCE MAP
Report page 1, main replication figure:
  evidence/replicated_figures_2_3.png (and the PDF version)
  evidence/trajectories.csv: time, position x1, velocity x2, input u, omega, alpha.
  evidence/author_figures/: six PDFs generated by the author's original script.

Numerical results and independent checks:
  evidence/metrics.csv: six cases, finite 5 s endpoints, analytical equilibrium,
  steady error, input peak, overshoot, independent-solver differences and the
  separate 30 s equilibrium check.
  evidence/verification.json: original run metadata and checks.
  evidence/run_log.txt: original run console output.

Comparison with the published paper:
  evidence/published_vector_points.csv: 715 extracted drawing vertices from
  12 curves in the paper's Figures 2 and 3, with comparison values.
  evidence/published_figure_comparison.csv: curve-level errors and endpoints.
  These vertices are PDF drawing coordinates, not raw experimental data or
  the author's original numerical samples. Differences include drawing
  simplification and coordinate precision.

Completed extension:
  evidence/alpha_sweep.csv: four alpha summaries across the three frequencies.
  evidence/alpha_sweep_trajectories.csv: the 12 full extension trajectories.
  evidence/alpha_tradeoff.png (and the PDF version): nominal responses and
  steady-error versus initial-input tradeoff.

The supplied results use a linear, unsaturated model. Analytical steady-state
values are distinct from the finite 5 s endpoints. Input is in model units.

The console log uses relative source paths in place of local machine paths.
Scientific outputs and simulation source files are otherwise preserved.

FINAL SENSITIVITY EVIDENCE
Figure 7: evidence/figure7_replication.png and .pdf; figure7_sensitivity.csv;
figure7_published_points.csv; figure7_selected_metrics.csv;
figure7_verification.json. There are 50 gain values, two intervals, 200 endpoint
simulations and 100 published drawing vertices. The measured curve is a 5 s
endpoint spread, distinct from analytical equilibrium width and reference error.
Design extension: evidence/design_constraints.json and analytical_sensitivity.csv.
